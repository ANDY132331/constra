# YouTube drafts: "Mission" series

Six vertical (1080x1920, 30 s) game-style spots for Constra, rendered in code from `marketing/vids/gta/core.js`. Each episode is a config in `marketing/vids/gta-epN/scene.js`.
All are uploaded as **private** drafts on the @getconstra channel; nothing is public until the owner flips it.

Re-render one: `node marketing/vids/render.mjs gta-ep3 video v` (set `OUTFILE=...` to choose the path). Contact sheet to check the look: `node marketing/vids/render.mjs gta-ep3 sheet v`.

All mission stats on screen (6/6, 0 late, 0 errors and so on) are fictional gameplay, not customer numbers. Do not turn them into claims.
